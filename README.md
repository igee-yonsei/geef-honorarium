# GEEF 연사료 서류 안내 페이지

연사가 거주자 여부와 거주국을 고르면, 보내야 할 서류와 양식을 안내하는 정적 페이지입니다.
개인정보를 받지 않고, 외부 글꼴·스크립트도 쓰지 않습니다(중국 본토에서도 열리도록).

## 구성
- `index.html` — 페이지 전체. 맨 위 `CONFIG`에 해마다 바꿀 값이 모여 있음
- `data/countries.csv` — 조세조약 국가 목록(국세법령정보시스템 조회 기준). 페이지는 `국가`, `영문명`, `ISO`, `분류코드` 열만 읽음
- `forms/` — 연사용 엑셀 양식 3종(**암호를 건 파일로 바꿔 올릴 것**)
- `assets/` — `igee-logo.png`, `geef-logo.png`를 넣으면 머리글에 표시(없으면 글자로 대체)

## 분류코드 → 페이지 안내
| 코드 | 의미 | 안내 |
|---|---|---|
| A, A2, C | 조약국(면제 가능) | 거주자증명서 + 조약국 양식 + 신청서 서명 |
| B, X | 조건이 붙은 조약국, 재무팀 확인 필요 | 증명서 + 조약국 양식, 결과는 담당자가 알림 |
| N / 목록에 없음 | 조약 없음 | 22% 원천징수 안내 + 미체결국 양식 |
| (거주자 판정 "예") | 국내 거주자 | 국내 거주자 양식 + 통장 사본 |

## GitHub Pages에 올리기
1. 공개 저장소를 만들고 이 폴더의 파일을 그대로 올림(암호·연사 명단·메일 주소 목록은 절대 올리지 않음)
2. Settings → Pages → Branch: `main`, 폴더 `/ (root)` → 저장
3. 1~2분 뒤 나오는 주소를 시크릿 창과 휴대폰에서 열어 확인

## 해마다 할 일
1. `index.html`의 `CONFIG`: 행사명·날짜, 메일 주소, 세 마감일, `certYear`, 양식 파일 경로
2. `forms/`: 연도 바꾼 양식 3종을 새 암호로 잠가 교체
3. `data/countries.csv`: 국세법령정보시스템에서 새 조약국·개정 의정서 확인 후 `확인일` 갱신
4. `CERT_LINKS`: 거주자증명서 발급 안내 링크가 살아 있는지 확인
